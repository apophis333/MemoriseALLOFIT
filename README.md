# MemoriseALLOFIT

A free, local-first memorisation app designed for GitHub Pages.

## Included
- Multiple practice modes including **Slider**
- Automatic chunking and chunk-based practice
- Spaced repetition and confidence tracking
- XP, streaks, achievements and daily challenges
- 14-day activity chart and detailed practice history
- English, Spanish, French, German and Japanese interface options
- Light, dark and system themes
- Browser text-to-speech
- Import/export backups
- Responsive mobile UI and offline PWA support
- Animated transitions with reduced-motion support

## Hosting
Upload the contents of this folder to a GitHub repository and enable GitHub Pages.

## Data
Everything is stored locally in the browser. There is no account or server database.

## Important
This is an original implementation. It does not use proprietary source code, branding, assets, or copied UI from other apps.

## GitHub Pages deployment
Make sure the entire project folder is uploaded, including `styles.css` and `assets/`. The site now references a root-level stylesheet so project/repository paths are more reliable.
